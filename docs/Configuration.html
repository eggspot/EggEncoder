API Reference

Configuration

EggEncoderOptions

The single configuration surface, set via the AddEggEncoder(Action<EggEncoderOptions>) delegate:

PropertyTypeDescription
UseNativeEncoderbooltrue resolves IMediaEncoder as NativeEncoder; false resolves FfmpegEncoder. Default false.
FfmpegBinPathstring?Directory containing ffmpeg.exe and ffprobe.exe. Required when UseNativeEncoder is false; ignored otherwise.

Native Engine

builder.Services.AddEggEncoder(options =>
{
    options.UseNativeEncoder = true;
});

No further configuration needed — the native codec binaries ship inside the NuGet package and are resolved relative to AppContext.BaseDirectory at runtime by NativeLibraryLoader.

Ffmpeg Engine

builder.Services.AddEggEncoder(options =>
{
    options.UseNativeEncoder = false;
    options.FfmpegBinPath = @"C:\tools\ffmpeg";
});

Binding from configuration works the same way as any other options pattern:

builder.Services.AddEggEncoder(options =>
    builder.Configuration.GetSection("EggEncoder").Bind(options));
{
  "EggEncoder": {
    "UseNativeEncoder": false,
    "FfmpegBinPath": "C:\\tools\\ffmpeg"
  }
}

Startup Failure Behavior

When UseNativeEncoder is false, FfmpegEncoderBinFactory's constructor checks for ffmpeg.exe and ffprobe.exe at FfmpegBinPath and throws FileNotFoundException immediately if either is missing. EggEncoder does not attempt to download, copy, or otherwise provision ffmpeg — the binaries must already exist at the configured path before IMediaEncoder is first resolved.
