IMediaEncoder

The core abstraction, implemented by NativeEncoder.

public interface IMediaEncoder
{
    Task<ProbeResult> Probe(string filePath);
    Task ConvertFile(string sourceFilePath, string destFilePath);
    Task CutFile(string sourceFilePath, string destFilePath, int startInSeconds, int endInSeconds);

ProbeResult

Only fields this library can genuinely compute are populated — no ffprobe-style placeholders (e.g. no probe_score, no disposition flags).

public class ProbeResult
{
    public string FormatName { get; init; }        // e.g. "wav", "flac", "mp3", "aac", "asf", "mov", "mp4"
    public string FormatLongName { get; init; }     // e.g. "WAV / WAVE (Waveform Audio)"
    public long SizeBytes { get; init; }
    public double DurationSeconds { get; init; }
    public string CodecType { get; init; }          // "audio" or "video"
    public string? CodecName { get; init; }         // e.g. "pcm_s16le", "flac", "mp3", "aac", "wmav2"
    public string? CodecLongName { get; init; }
    public int? SampleRate { get; init; }
    public int? Channels { get; init; }
    public string? ChannelLayout { get; init; }     // "mono", "stereo", or "{n} channels"
    public int? BitsPerSample { get; init; }
    public int? BitRate { get; init; }
    public bool? IsVariableBitRate { get; init; }   // MP3 only
    public long? DurationInSamples { get; init; }
    public string? TimeBase { get; init; }          // e.g. "1/44100"
    public int? Width { get; init; }                // set for video containers (MOV/MP4), null for audio
    public int? Height { get; init; }
    public IReadOnlyList<double>? Waveform { get; init; }  // normalized peak windows in [0,1], or null
    public double? PeakAmplitude { get; init; }     // loudest absolute sample across the whole decode, normalized to [0,1]
    public double? RmsLevel { get; init; }          // root-mean-square level across every sample, normalized to [0,1] (not ITU-R BS.1770 loudness)
}

AudioCutter

Namespace: EggEncoder.Codecs. Format-dispatching convert/cut used internally by NativeEncoder; also usable directly. The two-argument/four-argument Convert/Cut overloads are unchanged since the original release; the PcmTransformPipeline/CutOptions overloads and everything else below are new — see PCM Transform Pipeline.

public static class AudioCutter
{
    public static void Convert(string sourceFilePath, string destFilePath);
    public static bool Cut(string sourceFilePath, string destFilePath, int startInSeconds, int endInSeconds);

    // Pipeline-aware overloads: run every decoded block through a PcmTransformPipeline first.
    public static void Convert(string sourceFilePath, string destFilePath, PcmTransformPipeline pipeline);
    public static bool Cut(string sourceFilePath, string destFilePath, int startInSeconds, int endInSeconds, CutOptions options);

    // WavSampleFormat overloads: select a .wav destination's on-disk encoding (Integer, the default
    // matching every overload above, or Float32); ignored for non-WAV destinations, which throw
    // NotSupportedException if Float32 is requested against them.
    public static void Convert(string sourceFilePath, string destFilePath, WavSampleFormat destinationWavFormat);
    public static void Convert(string sourceFilePath, string destFilePath, PcmTransformPipeline pipeline, WavSampleFormat destinationWavFormat);

    // AiffSampleFormat overloads: same idea, for a .aiff/.aif/.aifc destination's on-disk encoding
    // (Integer, the default, or LittleEndianInteger/Float32/Float64/MuLaw/ALaw -- all of which write
    // an AIFC container). Also available via CutOptions.DestinationAiffFormat for Cut; Mix/Concatenate
    // don't have a dedicated AiffSampleFormat overload yet and always write Integer to an AIFF-family destination.
    public static void Convert(string sourceFilePath, string destFilePath, AiffSampleFormat destinationAiffFormat);
    public static void Convert(string sourceFilePath, string destFilePath, PcmTransformPipeline pipeline, AiffSampleFormat destinationAiffFormat);

    // AuSampleFormat overloads: same idea again, for a .au destination's on-disk encoding (Integer,
    // the default, or Float32/Float64/MuLaw/ALaw). Also available via CutOptions.DestinationAuFormat
    // for Cut; Mix/Concatenate don't have a dedicated AuSampleFormat overload yet either.
    public static void Convert(string sourceFilePath, string destFilePath, AuSampleFormat destinationAuFormat);
    public static void Convert(string sourceFilePath, string destFilePath, PcmTransformPipeline pipeline, AuSampleFormat destinationAuFormat);

    // Mixes 2+ same-format sources with per-input gain; decodes every input fully into memory, concurrently.
    public static void Mix(IReadOnlyList<MixInput> inputs, string destFilePath);
    public static void Mix(IReadOnlyList<MixInput> inputs, string destFilePath, WavSampleFormat destinationWavFormat);

    // Concatenates 2+ same-format sources, in order. Fully streaming for non-WAV destinations;
    // a WAV destination buffers the combined output in memory (see Advanced-Features.html).
    public static void Concatenate(IReadOnlyList<string> sourceFilePaths, string destFilePath);
    public static void Concatenate(IReadOnlyList<string> sourceFilePaths, string destFilePath, WavSampleFormat destinationWavFormat);

    // Decodes sourceFilePath fully to find its peak absolute sample value, for a true whole-file
    // PeakNormalizationTransform.MeasurePeak(long, int) measurement.
    public static (long Peak, int BitsPerSample) MeasurePeakAmplitude(string sourceFilePath);

    // Convenience float[] entry points -- see FloatSampleConverter below.
    public static (float[] Samples, int Channels, int SampleRate) ReadWavAsFloat(string sourceFilePath);
    public static void WriteWavFromFloat(string destFilePath, ReadOnlySpan<float> interleavedSamples, int channels, int sampleRate);
}

Cut decodes any supported source (.wav, .aiff/.aif/.aifc, .au, .caf, .flac, .mp3, .aac, .wma, .tta, .opus, .ogg, .wv, or .mov/.mp4 with a mono AAC-LC audio track) and writes any supported destination extension — source and destination don't need to match, so it can transcode while it trims. Returns false (and writes no file) if the requested range is entirely outside the source's duration.

PcmTransformPipeline & IPcmTransform — EggEncoder.Pcm

public interface IPcmTransform
{
    int OutputSampleRate { get; }      // 0 = passthrough
    int OutputChannels { get; }        // 0 = passthrough
    int OutputBitsPerSample { get; }   // 0 = passthrough
    bool CanChangeFrameCount { get; }
    (int[] buffer, int frameCount) Apply(int[] buffer, int frameCount, int channels, int sampleRate, int bitsPerSample);

    // Default interface method -- existing implementers don't need to change. Drains output this
    // transform is still holding back (e.g. a resampler's pending tail); call once, after the last
    // Apply() call for a stream. Most transforms hold no such state and keep the default (no output).
    (int[] buffer, int frameCount) Flush() => (Array.Empty<int>(), 0);
}

public sealed class PcmTransformPipeline
{
    public PcmTransformPipeline(params IPcmTransform[] transforms);
    public bool HasTransforms { get; }
    public IReadOnlyList<IPcmTransform> Transforms { get; }
    public bool CanChangeFrameCount { get; }
    public (int channels, int sampleRate, int bitsPerSample) ComputeOutputFormat(int inputChannels, int inputSampleRate, int inputBitsPerSample);
    public (int[] buffer, int frameCount, int channels, int sampleRate, int bitsPerSample) Apply(int[] inputBuffer, int frameCount, int channels, int sampleRate, int bitsPerSample);
    public (int[] buffer, int frameCount, int channels, int sampleRate, int bitsPerSample) Flush(int channels, int sampleRate, int bitsPerSample);
}

Apply is what AudioCutter.Convert/Cut call per decoded block; most consumers won't call it directly, but it's there if you're driving the pipeline yourself. Likewise Flush, which those same AudioCutter overloads call automatically once after the last block — see Advanced Features for why it exists and a worked example of calling it directly.

A pipeline instance carries cross-block state (a resampler's source history, a fade's frame position, a peak normalizer's measured gain) and is meant for exactly one Convert/Cut/Mix call — build a fresh one per call rather than reusing an instance across multiple calls.

    public void Reset(); // restart the two-state-value-per-channel filter history
}
public enum BiquadFilterType { LowPass, HighPass, BandPass, Notch, AllPass, PeakingEq, LowShelf, HighShelf }

public sealed class ButterworthTransform : IPcmTransform
{
    // filterType must be LowPass or HighPass (the other BiquadFilterType values have no standard
    // higher-order Butterworth cascade construction); order must be a positive even integer --
    // realized as order/2 cascaded BiquadTransform stages sharing the cutoff, each at its own Q
    // from the standard Butterworth pole-pair formula (maximally flat passband).
    public ButterworthTransform(BiquadFilterType filterType, int order, int channels, int sampleRate, double frequencyHz);
    public void Reset(); // restart every cascaded stage's filter history
}

public sealed class FirFilterTransform : IPcmTransform
{
    public FirFilterTransform(int channels, double[] taps); // applied identically to every channel; no filter-design code of its own
    public void Reset(); // restart each channel's taps.Length - 1 sample history
}

Parametric EQ and FIR filtering: BiquadTransform is a single second-order IIR section using the RBJ Audio EQ Cookbook formulas (Direct Form II Transposed, two state values per channel) — low/high pass, band pass, notch, all pass, peaking EQ, and low/high shelf. ButterworthTransform cascades order / 2 BiquadTransform stages sharing one cutoff frequency, each at a different Q from the standard Butterworth pole-pair formula, for a steeper, maximally-flat-passband low/high pass than a single biquad section can provide. FirFilterTransform is general FIR convolution (parity with ffmpeg's afir/general-FIR filters) — it applies a caller-supplied tap array identically to every channel and keeps each channel's last taps.Length - 1 samples as history across blocks; accepting arbitrary taps is the whole point, so there's no filter-design helper bundled with it.

Peak normalization used naively: if PeakNormalizationTransform is dropped into a pipeline and never pre-measured, MeasurePeak self-measures from whatever buffer Apply first sees — which, driven by AudioCutter.Convert/Cut, is one ~4096-frame decode block, not the whole file. For a true whole-file measurement, call AudioCutter.MeasurePeakAmplitude first and pass its result to MeasurePeak(long, int) before handing the transform to a pipeline.

Resampler quality: ResamplingTransform is a Kaiser-windowed-sinc polyphase filter — anti-aliasing on downsample, band-limited reconstruction on upsample — not linear interpolation. Output is held back until its full tap window (FilterHalfWidth source frames on each side) has genuinely arrived, rather than falling back to duplicating an edge sample at a block boundary; see Flush above for draining the last few frames this implies at the true end of a stream. Total output frame count is a cumulative floor(sourceFramesSoFar * ratio), so it's exact regardless of how a stream is split into blocks — no per-block rounding drift to account for. The continuous fractional source position is quantized to 1024 polyphase-table phases (a small, standard timing error for this class of resampler); downsampling scales the filter's half-width up by 1/cutoff to preserve anti-aliasing quality as the ratio shrinks, capped at 256 taps so an extreme ratio (e.g. 100:1) can't grow the table or per-sample cost unboundedly.

public readonly record struct MixInput(string FilePath, double Gain = 1.0);

public enum WavSampleFormat { Integer, Float32, MuLaw, ALaw }
public enum AiffSampleFormat { Integer, LittleEndianInteger, Float32, Float64, MuLaw, ALaw }
public enum AuSampleFormat { Integer, Float32, Float64, MuLaw, ALaw }

A fade, if requested, runs over the retained range before any transform in Pipeline. AudioCutter.Mix requires every input to share the same channels/sample rate/bit depth, and decodes all of them fully into memory, concurrently — clip-length material, not multi-hour streams. AudioCutter.Concatenate has the same format-matching requirement. WavSampleFormat selects a .wav destination's on-disk encoding (see Advanced Features for the float-WAV walkthrough); it's ignored for every other destination format. Float32 requires the destination's bit depth to already be 32; MuLaw/ALaw (G.711) require it to already be 16. AiffSampleFormat is the same idea for a .aiff/.aif/.aifc destination — LittleEndianInteger/Float32/Float64/MuLaw/ALaw all write an AIFC container regardless of which of those three extensions is used; Float32/Float64 require bit depth 32, MuLaw/ALaw require 16. AuSampleFormat is the same idea again for a .au destination — it has no LittleEndianInteger-equivalent value at all (AU is always big-endian), otherwise the same bit-depth requirements as AiffSampleFormat.

public sealed class WavWriter : IDisposable
{

    public void WriteInterleavedSamples(int[] buffer, int frameCount);
}

Supports 8-bit unsigned, 16/24/32-bit signed integer, and 32-bit IEEE float PCM (both read and write — WavSampleFormat.Float32 requires bitsPerSample: 32). Also supports G.711 mu-law/A-law companded PCM, both read and write (WavSampleFormat.MuLaw/ALaw require bitsPerSample: 16; any channel count, unlike every other codec here), and three ADPCM variants (IsImaAdpcm/IsMsAdpcm/IsYamahaAdpcm, picked up automatically from the file's own fmt chunk on read, no opt-in needed). IMA ADPCM, MS ADPCM, and Yamaha ADPCM are genuinely different algorithms despite the shared 4-bit coded width — IMA ADPCM uses one universal fixed step table, MS ADPCM carries its own linear-prediction coefficient table in the fmt chunk extension itself and groups its block header by field across channels rather than repeating it per channel, and Yamaha ADPCM has no block structure at all (no per-block header, no wSamplesPerBlock extension — each channel's predictor/step state just carries continuously for the whole stream). All three are mono/stereo only. WavWriter also encodes all three (WavSampleFormat.ImaAdpcm/MsAdpcm/YamahaAdpcm, bitsPerSample: 16 required). IMA ADPCM and MS ADPCM are block-structured, unlike every other WavSampleFormat value: samples are buffered internally into fixed-size blocks (1024-byte block align, matching FFmpeg's own real encoder defaults) and only physically written once a block fills or WriteInterleavedSamples's caller calls Finish(), which also flushes and pads any final short block. Yamaha ADPCM instead writes two samples per byte continuously as they arrive, only ever holding back the one trailing nibble an odd mono frame count can leave pending, which Finish() flushes zero-padded. IMA ADPCM's own nibble is chosen by an 8-candidate search that always agrees with how this project's own decoder would reconstruct it, so encode and decode can never drift out of sync; MS ADPCM's and Yamaha ADPCM's own nibbles are each computed via their own direct closed-form formula instead (confirmed FFmpeg's real encoders' internal state-tracking formulas structurally match their own decoders', unlike IMA ADPCM's, so no search is needed), and MS ADPCM's encoder always selects the standard coefficient table's simplest pair for every block, matching FFmpeg's own real encoder exactly. All three are verified bit-exact against a real, independent ffmpeg decode of files they produced. Samples are always exchanged as int[], at this codebase's native-range convention for whatever bit depth is in play (see PCM Transform Pipeline); for float format that range is the full 32-bit int range, matching what a normalized -1.0..1.0 float sample maps to.

public enum AiffSampleFormat { Integer, LittleEndianInteger, Float32, Float64, MuLaw, ALaw }

Plain AIFF (FORM/AIFF, 8/16/24/32-bit signed integer PCM — 8-bit is signed, unlike WAV's unsigned convention) both read and write under AiffSampleFormat.Integer, the default — byte-for-byte what this type has always produced, under the .aiff/.aif extensions. AiffReader additionally reads AIFC (FORM/AIFC) under the same extensions plus .aifc, with no separate dispatch beyond that extension list — just an extra compressionType field it understands in COMM. Every other AiffSampleFormat value writes AIFC instead: LittleEndianInteger ('sowt'), Float32/Float64 ('fl32'/'fl64', big-endian IEEE float decoded at this codebase's usual int32-native-range scale — both report BitsPerSample 32, since this project's int[] model has no 64-bit representation and 64 is purely fl64's on-disk coded width), and MuLaw/ALaw ('ulaw'/'alaw', G.711, via the same G711Codec the WAV side uses). AIFC's 'ima4' (QuickTime IMA4 ADPCM) compressionType is also decoded (decode only — AiffWriter never writes it) — its block framing is a materially different bitstream from WAV's own IMA ADPCM (no verbatim first sample per block, and stereo stores each channel's complete 34-byte sub-block consecutively rather than nibble-interleaving), though the underlying per-nibble math is identical and reused directly from Wav.ImaAdpcmDecoder. Any other, genuinely unsupported compressionType (e.g. 'MAC3'/MACE) still makes Open throw NotSupportedException naming it specifically. Samples are always exchanged as int[] at the native range for whatever bit depth is in play, the same convention WAV uses.

Sun/NeXT AU (magic .snd, mime audio/basic) — a much simpler container than WAV/AIFF, with no chunk structure at all: one fixed 24-byte header, optionally followed by an annotation string (never parsed), then raw big-endian samples with no byte-alignment padding requirement. AuSampleFormat.Integer (the default) covers 8/16/24/32-bit signed integer PCM — AU's 8-bit is signed, the same convention AIFF uses, not WAV's unsigned one. Float32/Float64 are big-endian IEEE float decoded at this codebase's usual int32-native-range scale — both report BitsPerSample 32, the same "no 64-bit representation in this project's int[] model" reasoning AiffSampleFormat.Float64 already established. MuLaw/ALaw are G.711, via the same G711Codec the WAV and AIFF sides use. Every other defined AU encoding (G.721/G.722/G.723 ADPCM, fragmented samples) is real but obscure enough in practice that it's out of scope the same way AIFC's 'MAC3'/'MAC6' (MACE) are — Open throws NotSupportedException naming the unrecognized encoding value. AU also has its own "unknown data size" sentinel a real streaming file can use; AuReader reads until end-of-file for it, though AuWriter never writes it (it always knows its exact totalFrames up front, like WavWriter/AiffWriter).

Apple Lossless, in a CAF container (.caf). Mono and stereo, 16-bit or 24-bit integer PCM only — throws NotSupportedException for any other channel count or bit depth (20-bit and 32-bit are out of scope, matching ffmpeg's own ALAC encoder, which doesn't emit those depths either). For stereo, the encoder tries a fixed mid/side mix first (the classic 0.5-weight split, expressed through ALAC's general affine decorrelation), falling back to independent channels and then to a verbatim (uncompressed) frame only if the previous option's residuals would overflow the Rice coder's escape code.

Decode Callback Signature

Every codec's Decode method streams blocks through the same callback shape rather than returning the full signal in memory. It's a plain delegate rather than a generic Action<> because ReadOnlySpan<int> can't be used as a generic type argument on net8.0:

namespace EggEncoder.Codecs;

public delegate void AudioBlockDecodedCallback(ReadOnlySpan<int> block, int channels, int sampleRate, int bitsPerSample, long totalSamplesPerChannel);

block is interleaved samples for whatever chunk the decoder just produced — accumulate it yourself (into a List<int>, a WaveformCalculator, an IAudioSink) as needed.
