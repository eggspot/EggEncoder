IMediaEncoder

The core abstraction, implemented by NativeEncoder.

public interface IMediaEncoder
{
    Task<ProbeResult> Probe(string filePath);
    Task ConvertFile(string sourceFilePath, string destFilePath);
    Task CutFile(string sourceFilePath, string destFilePath, int startInSeconds, int endInSeconds);
}

ProbeResult

Only fields this library can genuinely compute are populated — no ffprobe-style placeholders (e.g. no probe_score, no disposition flags).

public class ProbeResult
{
    public string FormatName { get; init; }        // e.g. "wav", "flac", "mp3", "aac", "asf", "mov", "mp4"
    public string FormatLongName { get; init; }     // e.g. "WAV / WAVE (Waveform Audio)"
    public long SizeBytes { get; init; }
    public double DurationSeconds { get; init; }
    public string CodecType { get; init; }          // "audio" or "video"
    public string? CodecName { get; init; }         // e.g. "pcm_s16le", "flac", "mp3", "aac", "wmav2"
    public string? CodecLongName { get; init; }
    public int? SampleRate { get; init; }
    public int? Channels { get; init; }
    public string? ChannelLayout { get; init; }     // "mono", "stereo", or "{n} channels"
    public int? BitsPerSample { get; init; }
    public int? BitRate { get; init; }
    public bool? IsVariableBitRate { get; init; }   // MP3 only
    public long? DurationInSamples { get; init; }
    public string? TimeBase { get; init; }          // e.g. "1/44100"
    public int? Width { get; init; }                // set for video containers (MOV/MP4), null for audio
    public int? Height { get; init; }
    public IReadOnlyList<double>? Waveform { get; init; }  // normalized peak windows in [0,1], or null
}

NativeEncoder

Namespace: EggEncoder. Dispatches to a codec under Codecs/ by file extension. No external process.

public class NativeEncoder : IMediaEncoder

    public NativeEncoder(ILogger<NativeEncoder> logger);

Supported extensions for Probe: .wav, .flac, .mp3, .aac, .wma, .mov, .mp4. Unrecognized extensions throw NotSupportedException.

AudioCutter

Namespace: EggEncoder.Codecs. Format-dispatching convert/cut used internally by NativeEncoder; also usable directly. The two-argument/four-argument Convert/Cut overloads are unchanged since the original release; the PcmTransformPipeline/CutOptions overloads and everything else below are new — see PCM Transform Pipeline.

public static class AudioCutter
{
    public static void Convert(string sourceFilePath, string destFilePath);
    public static bool Cut(string sourceFilePath, string destFilePath, int startInSeconds, int endInSeconds);

    // Pipeline-aware overloads: run every decoded block through a PcmTransformPipeline first.
    public static void Convert(string sourceFilePath, string destFilePath, PcmTransformPipeline pipeline);
    public static bool Cut(string sourceFilePath, string destFilePath, int startInSeconds, int endInSeconds, CutOptions options);

    // WavSampleFormat overloads: select a .wav destination's on-disk encoding (Integer, the default
    // matching every overload above, or Float32); ignored for non-WAV destinations, which throw
    // NotSupportedException if Float32 is requested against them.
    public static void Convert(string sourceFilePath, string destFilePath, WavSampleFormat destinationWavFormat);
    public static void Convert(string sourceFilePath, string destFilePath, PcmTransformPipeline pipeline, WavSampleFormat destinationWavFormat);

    // Mixes 2+ same-format sources with per-input gain; decodes every input fully into memory, concurrently.
    public static void Mix(IReadOnlyList<MixInput> inputs, string destFilePath);
    public static void Mix(IReadOnlyList<MixInput> inputs, string destFilePath, WavSampleFormat destinationWavFormat);

    // Concatenates 2+ same-format sources, in order. Fully streaming for non-WAV destinations;
    // a WAV destination buffers the combined output in memory (see Advanced-Features.html).
    public static void Concatenate(IReadOnlyList<string> sourceFilePaths, string destFilePath);
    public static void Concatenate(IReadOnlyList<string> sourceFilePaths, string destFilePath, WavSampleFormat destinationWavFormat);

    // Decodes sourceFilePath fully to find its peak absolute sample value, for a true whole-file
    // PeakNormalizationTransform.MeasurePeak(long, int) measurement.
    public static (long Peak, int BitsPerSample) MeasurePeakAmplitude(string sourceFilePath);

    // Convenience float[] entry points -- see FloatSampleConverter below.
    public static (float[] Samples, int Channels, int SampleRate) ReadWavAsFloat(string sourceFilePath);
    public static void WriteWavFromFloat(string destFilePath, ReadOnlySpan<float> interleavedSamples, int channels, int sampleRate);
}

Cut decodes any supported source (.wav, .flac, .mp3, .aac, .wma, or .mov/.mp4 with a mono AAC-LC audio track) and writes any supported destination extension — source and destination don't need to match, so it can transcode while it trims. Returns false (and writes no file) if the requested range is entirely outside the source's duration.

PcmTransformPipeline & IPcmTransform — EggEncoder.Pcm

public interface IPcmTransform
{
    int OutputSampleRate { get; }      // 0 = passthrough
    int OutputChannels { get; }        // 0 = passthrough
    int OutputBitsPerSample { get; }   // 0 = passthrough
    bool CanChangeFrameCount { get; }
    (int[] buffer, int frameCount) Apply(int[] buffer, int frameCount, int channels, int sampleRate, int bitsPerSample);

    // Default interface method -- existing implementers don't need to change. Drains output this
    // transform is still holding back (e.g. a resampler's pending tail); call once, after the last
    // Apply() call for a stream. Most transforms hold no such state and keep the default (no output).
    (int[] buffer, int frameCount) Flush() => (Array.Empty<int>(), 0);
}

public sealed class PcmTransformPipeline
{
    public PcmTransformPipeline(params IPcmTransform[] transforms);
    public bool HasTransforms { get; }
    public IReadOnlyList<IPcmTransform> Transforms { get; }
    public bool CanChangeFrameCount { get; }
    public (int channels, int sampleRate, int bitsPerSample) ComputeOutputFormat(int inputChannels, int inputSampleRate, int inputBitsPerSample);
    public (int[] buffer, int frameCount, int channels, int sampleRate, int bitsPerSample) Apply(int[] inputBuffer, int frameCount, int channels, int sampleRate, int bitsPerSample);
    public (int[] buffer, int frameCount, int channels, int sampleRate, int bitsPerSample) Flush(int channels, int sampleRate, int bitsPerSample);
}

Apply is what AudioCutter.Convert/Cut call per decoded block; most consumers won't call it directly, but it's there if you're driving the pipeline yourself. Likewise Flush, which those same AudioCutter overloads call automatically once after the last block — see Advanced Features for why it exists and a worked example of calling it directly.

A pipeline instance carries cross-block state (a resampler's source history, a fade's frame position, a peak normalizer's measured gain) and is meant for exactly one Convert/Cut/Mix call — build a fresh one per call rather than reusing an instance across multiple calls.

Transforms — EggEncoder.Pcm

public sealed class ResamplingTransform : IPcmTransform
{
    public const int DefaultFilterHalfWidth = 32;

    public ResamplingTransform(int sourceRate, int targetRate, int channels, int filterHalfWidth = DefaultFilterHalfWidth);
    public int FilterHalfWidth { get; } // the effective half-width actually used, after any downsampling scale-up/cap
    public void Reset(); // restart all cross-block state (history, stream position, flushed flag)
    // Flush() drains the last few output frames a full lookahead window couldn't yet be gathered for; see above.
}

public sealed class VolumeTransform : IPcmTransform

public sealed class PeakNormalizationTransform : IPcmTransform

    public void MeasurePeak(int[] buffer, int frameCount, int channels, int bitsPerSample);
    public void MeasurePeak(long maxAbsoluteSample, int bitsPerSample);
    public static long ComputeMaxAbsoluteSample(ReadOnlySpan<int> samples);
}

public enum ChannelRemixMode { Auto, PassThrough, Downmix, UpMix }

public sealed class BitDepthFormatTransform : IPcmTransform
{
    public BitDepthFormatTransform(int fromBits, int toBits); // each 8, 16, 24, or 32
    public static (long Min, long Max) GetNativeRange(int bits);
}

public sealed class FadeTransform : IPcmTransform
{
    public FadeTransform(long totalFrames, long fadeInFrames = 0, long fadeOutFrames = 0, FadeCurve curve = FadeCurve.Linear);
    public void Reset(); // restart the cross-block frame position tracker
}
public enum FadeCurve { Linear, EqualPower }

Peak normalization used naively: if PeakNormalizationTransform is dropped into a pipeline and never pre-measured, MeasurePeak self-measures from whatever buffer Apply first sees — which, driven by AudioCutter.Convert/Cut, is one ~4096-frame decode block, not the whole file. For a true whole-file measurement, call AudioCutter.MeasurePeakAmplitude first and pass its result to MeasurePeak(long, int) before handing the transform to a pipeline.

Resampler quality: ResamplingTransform is a Kaiser-windowed-sinc polyphase filter — anti-aliasing on downsample, band-limited reconstruction on upsample — not linear interpolation. Output is held back until its full tap window (FilterHalfWidth source frames on each side) has genuinely arrived, rather than falling back to duplicating an edge sample at a block boundary; see Flush above for draining the last few frames this implies at the true end of a stream. Total output frame count is a cumulative floor(sourceFramesSoFar * ratio), so it's exact regardless of how a stream is split into blocks — no per-block rounding drift to account for. The continuous fractional source position is quantized to 1024 polyphase-table phases (a small, standard timing error for this class of resampler); downsampling scales the filter's half-width up by 1/cutoff to preserve anti-aliasing quality as the ratio shrinks, capped at 256 taps so an extreme ratio (e.g. 100:1) can't grow the table or per-sample cost unboundedly.

    public double FadeInSeconds { get; init; }
    public double FadeOutSeconds { get; init; }
    public FadeCurve FadeCurve { get; init; } = FadeCurve.Linear;
    public WavSampleFormat DestinationWavFormat { get; init; } = WavSampleFormat.Integer;
}

public readonly record struct MixInput(string FilePath, double Gain = 1.0);

public enum WavSampleFormat { Integer, Float32, MuLaw, ALaw }

A fade, if requested, runs over the retained range before any transform in Pipeline. AudioCutter.Mix requires every input to share the same channels/sample rate/bit depth, and decodes all of them fully into memory, concurrently — clip-length material, not multi-hour streams. AudioCutter.Concatenate has the same format-matching requirement. WavSampleFormat selects a .wav destination's on-disk encoding (see Advanced Features for the float-WAV walkthrough); it's ignored for every other destination format. Float32 requires the destination's bit depth to already be 32; MuLaw/ALaw (G.711) require it to already be 16.

FloatSampleConverter — EggEncoder.Pcm

public static class FloatSampleConverter
{
    public static int[] FromFloat(ReadOnlySpan<float> floatSamples);           // -1.0..1.0 -> 32-bit native range
    public static float[] ToFloat(ReadOnlySpan<int> samples, int bitsPerSample); // any native range -> -1.0..1.0
}

The pipeline itself is exclusively int[]-based; a normalized float sample maps 1:1 onto the 32-bit int native range (the same scale WavReader/WavWriter use for IEEE float WAV). Use this type when you have (or want) float[] directly rather than a WAV file — AudioCutter.ReadWavAsFloat/WriteWavFromFloat wrap it for the WAV case.

    public int SampleRate { get; }
    public int BitsPerSample { get; }
    public long TotalSamples { get; }
    public bool IsFloatFormat { get; }
    public bool IsALaw { get; }
    public bool IsMuLaw { get; }
    public bool IsImaAdpcm { get; }
    public int ReadInterleavedSamples(int[] buffer, int maxSamplesPerChannel);
}

public sealed class WavWriter : IDisposable
{
    public static WavWriter Create(string destFilePath, int channels, int sampleRate, int bitsPerSample, long totalFrames, WavSampleFormat sampleFormat = WavSampleFormat.Integer);
    public void WriteInterleavedSamples(int[] buffer, int frameCount);
}

Supports 8-bit unsigned, 16/24/32-bit signed integer, and 32-bit IEEE float PCM (both read and write — WavSampleFormat.Float32 requires bitsPerSample: 32). Also supports G.711 mu-law/A-law companded PCM, both read and write (WavSampleFormat.MuLaw/ALaw require bitsPerSample: 16; any channel count, unlike every other codec here), and IMA ADPCM, read only (IsImaAdpcm; picked up automatically from the file's own fmt chunk, no write-side option exists). Samples are always exchanged as int[], at this codebase's native-range convention for whatever bit depth is in play (see PCM Transform Pipeline); for float format that range is the full 32-bit int range, matching what a normalized -1.0..1.0 float sample maps to.

Decode Callback Signature

Every codec's Decode method streams blocks through the same callback shape rather than returning the full signal in memory. It's a plain delegate rather than a generic Action<> because ReadOnlySpan<int> can't be used as a generic type argument on net8.0:

namespace EggEncoder.Codecs;

public delegate void AudioBlockDecodedCallback(ReadOnlySpan<int> block, int channels, int sampleRate, int bitsPerSample, long totalSamplesPerChannel);

block is interleaved samples for whatever chunk the decoder just produced — accumulate it yourself (into a List<int>, a WaveformCalculator, an IAudioSink) as needed.
